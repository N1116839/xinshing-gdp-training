## 簡報嚴格規格
```
這份簡報是正式對台灣食藥署稽查員報告用，不是內部教育訓練、不是稽查背稿、不是資料整理表。
```
### 風格
```
- 封面直接使用 `新勝封面.png`，不得新增任何文字、頁碼或物件。
- 內頁需對齊封面風格：乾淨、正式、淺天藍背景、墨綠色識別、橘金標題。
- 全繁體中文，文字置中，字體一致，使用 Microsoft JhengHei 或同等粗圓黑體感。
- 標題、內文、表格、圖形內文字必須字體一致，不可同頁混用不同視覺語氣。
- 每頁右下角要有頁碼；頁尾維持公司標語。
- 16:9 寬螢幕。
```
### 呈現方式
```
- 必須是正式報告語氣，以「公司已建立並執行的制度」來呈現。
- 要善用資訊圖表、流程圖、時間軸、責任分工圖、KPI、矩陣與管制點圖。
- 不可只有文字與表格；表格只能作為輔助，不可成為主要視覺。
- 圖與文字不得互相遮擋；文字必須完整放在箭頭、面板或表格欄位內。
- 組織圖不要直接貼低品質原圖；應依 WI10-01/組織圖內容重畫成乾淨可編輯圖形。
- 所有數字、SOP 條件、頻率、但書必須可追溯至文件內容，不可自行推論。
```
### 禁止事項
```
- 禁止使用簡體中文。
- 禁止使用陰影、漸層、半透明、圓角卡片等不符合原規格的裝飾。
- 禁止重繪、縮放或改造原始 Logo。
- 禁止出現「稽查員可能問」、「可直接回答」、「稽查應答」、「可提示文件」、「稽查證據」、「稽查期待」、「合規結論」等不適合正式報告的字眼。
- 禁止讓簡報看起來像內部教育訓練或背誦稽查答案。
- 禁止使用未確認的冷鏈內容；目前不應呈現 `冷鏈警戒值` 或 `3.5/6.5°C`。
- 禁止出現已被指出的錯字或不精準詞，例如 `補蟻盒`、`警戒限`。
```
